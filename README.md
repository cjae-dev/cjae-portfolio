# Cjae React Portfolio

A dark, animated React portfolio inspired by modern developer showcase videos.

## Features

- React + Vite setup
- Dark cinematic UI
- Animated hero section
- Interactive project showcase
- Admin CMS/login mockup section
- Marquee skill animation
- Scroll reveal transitions
- Responsive layout
- Existing portfolio assets included

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.

## Build

```bash
npm run build
```

## Main files

```txt
src/App.jsx
src/styles.css
src/components/
src/data/projects.js
public/images/
public/files/
```

Update project details inside:

```txt
src/data/projects.js
```
